# Third-Party Notices

## Coding guidelines in CLAUDE.md.template (credit / inspiration)

The four "behavioral guidelines" in `CLAUDE.md.template` (clarify before you build,
build the smallest thing that works, keep diffs narrow, define done then prove it)
are inspired by the themes in **andrej-karpathy-skills** by Forrest Chang
(https://github.com/forrestchang/andrej-karpathy-skills, now
https://github.com/multica-ai/andrej-karpathy-skills), which in turn draws on
Andrej Karpathy's public observations about LLM coding pitfalls.

That repository's README states "License: MIT", but at the time of review
(2026-10-18) it shipped no LICENSE file or copyright notice. To avoid any
ambiguity, no text from it is reproduced here: the guidelines in this kit were
rewritten in original wording. Only the general ideas, which are not subject to
copyright, are shared. Credit for the original framing goes to its authors.

No other third-party code or text is included in this kit.
